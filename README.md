# CoronaVIR: A Web-Based Platform on Coronavirus Disease-19 to Maintain Predicted Diagnostic, Drug, and Vaccine Candidates

**CoronaVIR** is a comprehensive, multi-modular web resource developed to maintain both predicted and existing scientific information on **SARS-CoV-2**. This platform serves as a holistic toolkit for the scientific community,
integrating genomic analysis, diagnostic tool development, and the discovery of therapeutic and vaccine candidates to combat the COVID-19 pandemic.

**Web Server:** https://webs.iiitd.edu.in/raghava/coronavir/

## About the Platform

CoronaVIR was established to consolidate rapidly evolving data on the severe acute respiratory syndrome coronavirus 2 (SARS-CoV-2). It employs state-of-the-art *in silico* techniques to provide high-confidence
predictions for diagnostics and therapeutics, ensuring that researchers have access to the latest computational insights.

* **Holistic Approach:** Integrates four major modules: Genomics, Diagnosis, Immunotherapy, and Drug Designing.
* **Universal Coverage:** Focuses on identifying candidates (like primers and epitopes) that are effective across all known strains of the virus.

---

## Key Features

### 1. Genomics Module

* **Strain Analysis:** Provides detailed genomic information on different viral strains to track and understand genomic-level alterations and mutations.
* **Evolutionary Insights:** Assists researchers in monitoring how the virus changes over time and across different geographic regions.

### 2. Diagnosis Module

* **Universal Primers:** Features five novel universal primer sets predicted using *in silico* tools, designed to be effective even as the virus evolves.
* **Current Tests:** Maintains a comprehensive database of diagnostic tests currently in clinical use.

### 3. Immunotherapy Module

* **Epitope Prediction:** Identifies potential vaccine candidates capable of activating both adaptive (B-cell and T-cell) and innate (vaccine adjuvants) immune systems.
* **Next-Gen Therapies:** Includes predictions for siRNA-based therapies and RNA-based vaccine adjuvants.

### 4. Drug Designing Module

* **Target Identification:** Catalogs potential drug targets and provides their predicted tertiary structures.
* **Virtual Screening:** Features a database of potential drug molecules identified from FDA-approved drugs using docking-based repurposing approaches.
* **Host-Virus Interaction:** Includes data on cell-penetrating peptides identified within the virus to understand how it gains cellular entry.

---

## Applications

* **Vaccine Development:** Prioritizing immunogenic epitopes for experimental validation in multi-epitope vaccine design.
* **Drug Repurposing:** Identifying existing, safe medications that can be quickly pivoted for COVID-19 treatment.
* **Diagnostic Innovation:** Providing optimized primer sequences for the development of more sensitive and universal RT-PCR assays.
